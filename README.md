# Distance-Decayed Memory for Autoregressive Video Prediction

This research project tests whether a causal video model can preserve long-range
visual consistency more effectively by compressing older cache entries smoothly
with distance, rather than dropping them at a sliding-window boundary. The active
work is the controlled Track A study on Memory Maze; Track B is deferred until
the owner reopens it after Gate 2.
